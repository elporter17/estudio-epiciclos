# Temas pendientes para el explicador (motor «explica»)

Ideas nuevas que todavía no se publicaron ni están en la cola (revisado el 2026-11-28 contra `video3d/guiones/cola` y `video3d/guiones/archivo`).
Para escribirlas: agentes con el brief de siempre (ver los guiones de la cola como ejemplo) y, antes de dibujar, `node scripts/biblioteca-buscar.mjs <palabras> --png`.
Al terminar cada tanda: `node scripts/validar-guiones.mjs`, render de revisión y `node scripts/biblioteca-cosechar.mjs`.
