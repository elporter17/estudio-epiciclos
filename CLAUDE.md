# CirculArte · contexto para Claude Code

Web que dibuja imágenes, textos y funciones con círculos que giran (series de Fourier / epiciclos) y graba el video. En producción: https://circularte.edav-tech.com (Vercel, se despliega solo desde `main`). Historia completa y decisiones: [docs/CONTEXTO.md](docs/CONTEXTO.md).

## Estructura
- `index.html`: la web (UI). Importa `src/engine.js` (motor: matemática + dibujo, compartido con Node), `src/captions.js` (descripciones y hashtags con plantillas, compartido con `caption.mjs`) y `src/tiktok-ui.js` (diálogo «Publicar en TikTok»).
- La web tiene lo mismo que la publicación automática: **Modo suspenso** (guía 0, ganchos sin el nombre, descripción sin spoiler, portada al 45 % con `cover_ms` → `video_cover_timestamp_ms`), **Máximo detalle** (`NSEQ_DETAIL`, hasta N = 500) y **🎲 Figura compleja al azar** (presets sin `simple` y `COMPLEX_TYPES`).
- **Estilos de nombre**: `espejo` y `mandala` son `NAME_VARIANTS` de `src/engine.js` (cambian la silueta del texto con `variantCanvas` antes de la serie; `daily.mjs` los renderiza con `style: 'z'` para que salgan grandes; espejo escribe el nombre al final con `drawRevealText`). `hilos`, `anillos` y `costura` están en `src/nombres-arte.js` (mismo contrato que `src/fisica.js`: `buildArte` da una corrida con `events` para `synthAudio`, siempre con melodía; `drawArte` dibuja un instante, con caché de lo ya dibujado) y se renderizan con `scripts/arte.mjs`. `pickNext` añade `style` a nombres y parejas (`NAME_STYLES_BY_CAT`) y lo guarda en el historial; las descripciones usan `MYSTERY_CAT['<cat>-<estilo>']`. En la web, la pestaña Texto tiene «Estilo» y las tres animaciones propias se reproducen por el mismo camino que las pelotas (`bounceRun.arte`).
- **Famosos** (`cats: famosos`, workflow `famosos.yml` que reutiliza `daily.yml`): `data/famosos.json` (id, nombre, tipo cara|pose|gol|logo, prompt, imagen). `catalog` solo incluye las que tienen `assets/famosos/<id>.png`. Se dibujan con `resolveSource({ image })` (silueta con alfa, `maxDim` 800, `tint` para la figura final en el color del trazo) y `revealText` con el nombre; ganchos en `FAMOSO_HOOKS`/`famosoHook` y descripciones `famosos-<tipo>` en `src/captions.js`. `scripts/lib/famosos.mjs` limpia imágenes (Otsu, fondo por el borde, sin manchitas, recorte); la usan `famosos-imagenes.mjs` (OpenAI, `gpt-image-2.5-flare`, clave de `../minidramas/.env` con `--env-file`; el filtro rechazó a veces las de Messi: un prompt sin el nombre pasó) y `silueta.mjs` (`npm run silueta`, bandeja `siluetas/<tipo>/`, ignorada por git).
- **Portada**: `drawCoverText` y `COVER_SECONDS` en `src/engine.js`; `render.mjs` y `arte.mjs` con `--cover` dibujan primero el dibujo avanzado (`T.draw * 0.72`, o 70 % de la animación) sin rótulos (`R.noLabels`) y una píldora; `daily.mjs` la pone en nombres, parejas y famosos (`coverText` en `captions.js`) y usa `NSEQ_TIKTOK` (empieza en N = 8).
- `data/biblioteca.json` (221 nombres latinos comunes, 100 parejas armadas con los más comunes, 100 figuras de emoji revisadas a ojo; el 2026-10-28 se quitaron los nombres raros) alimenta la publicación automática: `catalog({ complex: true })` usa esas figuras en vez de los presets de emoji, cada elemento lleva `cat` y `pick.mjs` reparte con `SHARES` (nombres 50, parejas 17, figuras 20, inventadas 13; los nombres pueden seguir a otro nombre) y evita las últimas 60 corridas (las inventadas no se bloquean). - **Pelotas** (`src/bounce.js`, compartido): simulación determinista con semilla (fotos a 60 fps + lista de rebotes), dibujo y síntesis de notas (pentatónica, cuerda pulsada). `scripts/bounce.mjs` las renderiza con audio AAC; en la web, la pestaña Pelotas suena con Web Audio (el reloj del audio manda la animación) y la grabación lleva la pista por un `MediaStreamDestination`. En la publicación automática son la categoría `pelotas` (20 %), con ganchos y hashtags propios (`pelotas-<modo>` en `captions.js`).
- **Juegos de física** (`src/arcade.js`): embudos, anillos que giran, plinko, carrera de colores, carrera de países (banderas emoji; en la web se carga solo ese pedazo de Noto Color Emoji porque la fuente de Windows no trae banderas), muros (segmentos con vida; pasados 20 s cada choque rompe el segmento entero) y batalla (dos pelotas con arma; se atraen un poco y el daño crece con el tiempo para que terminen antes de 40 s; al chocar las armas se empujan para no trabarse). Si TikTok ya tiene 5 borradores pendientes, `daily.mjs` no falla (estado `LIMIT`) y el video queda como artefacto. ## Comandos
```bash
npm install && npm run fonts          # una vez (Noto Color Emoji)
npm run render -- --preset Violín --lang en
npm run caption -- --meta out/<video>.json
npm run tiktok:connect                 # CLI, cuenta del sandbox
npm run publish -- --video out/<video>.mp4 --mode draft
npm run daily -- --publish direct      # público, con descripción (draft = bandeja)
```
En PowerShell 5.1 usa `npm.cmd run … -- …` (PowerShell se come el `--`).
